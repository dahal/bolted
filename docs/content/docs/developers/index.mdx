## A note on audience

Code-level reference (function signatures, package APIs) lives in the Go source - `pkg.go.dev` will render it once the module is published. These pages cover the _prose_ of the codebase: design decisions, conventions, and the rationale behind the package layout. They link out to the actual code where the implementation matters.
