---
title: bolt status
description: Show Bolted state - VM, lock, repos, containers.
---

Prints a summary of the Bolted's current state: whether the VM is running, whether the volume is unlocked, which repos exist, and whether their dev containers are up. Always safe to call.

## Synopsis

```sh
bolt status [flags]
```

## Flags

| Flag     | Description                                                      |
| -------- | ---------------------------------------------------------------- |
| `--json` | Emit machine-readable JSON instead of the human-readable summary |

## Examples

Human output:

```sh
bolt status
```

```
Lock:       unlocked
VM:         running (cpus=4 memory=8GB disk=50GB)
VM RSS:     1234 MiB
Repos:      2
  - api
  - web
Containers: -
```

Machine-readable for scripts:

```sh
bolt status --json
```

```json
{
  "initialized": true,
  "locked": false,
  "vm": {
    "state": "running",
    "cpus": 4,
    "memory": "8GB",
    "disk": "50GB",
    "rss_mb": 1234
  },
  "repos": {
    "count": 2,
    "names": ["api", "web"]
  },
  "containers": "-"
}
```

## Exit codes

| Code | Meaning                                             |
| ---- | --------------------------------------------------- |
| `0`  | Success (bolt initialised, info printed)            |
| `1`  | Generic error (couldn't probe VM state, etc.)       |
| `2`  | Bolted not initialised (`bolt init` hasn't run yet) |
